Place PDF font files here for server-generated PDFs:
- NotoSansDevanagari-Regular.ttf
- NotoSans-Regular.ttf (optional, for non-Devanagari text)
- NotoEmoji-Regular.ttf (optional, for emoji glyphs)
Alternatively set env vars:
  PDF_DEVANAGARI_FONT_PATH, PDF_LATIN_FONT_PATH, PDF_EMOJI_FONT_PATH
  PDF_DEVANAGARI_FONT_BASE64, PDF_LATIN_FONT_BASE64, PDF_EMOJI_FONT_BASE64
