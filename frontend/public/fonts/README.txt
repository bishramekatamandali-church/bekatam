Place these font files here so browser-generated PDFs support Nepali (Devanagari):
- NotoSansDevanagari-Regular.ttf
- NotoSansDevanagari-Bold.ttf (optional)
- NotoEmoji-Regular.ttf (optional, for emoji glyphs)
You can download them from Google Noto Fonts or install fonts-noto on your system and copy them.
